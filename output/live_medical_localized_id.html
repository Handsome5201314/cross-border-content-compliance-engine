objections

  • topic

    price

    question

    Berapa harga pasti untuk lisensi perangkat lunak?

    answer

    Harga disesuaikan dengan skala rumah sakit dan jumlah pengguna. Kami tidak menampilkan harga publik karena ini adalah solusi B2B. Silakan hubungi tim penjualan kami untuk penawaran khusus.

  • topic

    deployment

    question

    Apakah sulit menginstal sistem ini di infrastruktur IT kami?

    answer

    Sistem dirancang untuk kemudahan instalasi dengan perangkat keras plug-and-play. Tim teknis kami akan membantu integrasi awal dengan server lokal Anda.

  • topic

    security

    question

    Bagaimana Anda menjamin keamanan data pasien?

    answer

    Kami tidak menggunakan kata 'menjamin' secara mutlak, tetapi desain sistem memastikan 100% pemrosesan data di lokal. Data tidak dikirim ke cloud API, dan file asli dihapus setelah pemrosesan.

  • topic

    certification

    question

    Apakah produk ini memiliki sertifikasi FDA atau CE?

    answer

    Saat ini, produk ini adalah hasil proyek kolaborasi rumah sakit dan belum memiliki sertifikasi FDA atau CE. Kepatuhan terhadap regulasi lokal seperti izin edar harus diverifikasi sesuai yurisdiksi masing-masing.

  • topic

    languages

    question

    Apakah sistem mendukung Bahasa Indonesia dengan baik?

    answer

    Ya, sistem dilatih dan dioptimalkan untuk Bahasa Indonesia, termasuk istilah medis lokal. Kami juga mendukung bahasa lain sesuai kebutuhan pasar target.

  • topic

    support

    question

    Apa yang terjadi jika sistem mengalami gangguan?

    answer

    Kami menyediakan dukungan teknis untuk pemeliharaan sistem lokal. Karena sistem berjalan di infrastruktur Anda, tim IT rumah sakit juga memiliki kontrol penuh atas ketersediaan layanan.
