solution

An integrated software and hardware solution designed for pediatric residents. The software runs entirely on local hospital GPUs, handling automatic speech recognition, optical character recognition, and clinical documentation generation. A planned smart badge hardware component aims to automate audio capture and context association. The system ensures patient data remains within the hospital infrastructure, with raw recordings and images deleted after processing.

compliance

data_sovereignty

All data processing, including OCR, visual verification, transcription, and de-identification, occurs on local hospital GPUs (RTX 3090 24GB). No patient data is transmitted to cloud APIs. Raw audio and images are deleted immediately after processing. This design supports data localization requirements, but specific regulatory compliance (such as GDPR, Indonesia PDPA, or Saudi/UAE data laws) must be verified by the purchasing institution according to local jurisdiction.

market_access

This product is a software tool and hardware prototype intended for professional use within hospital environments. It does not carry medical device certifications such as FDA, CE, or SFDA. Compliance with local medical device regulations is the responsibility of the deploying institution. Cross-border data transfer assessments are not required for the software's operation as no data leaves the local premises, but legal obligations for the institution must be assessed separately.

faq

  • topic

    deployment

    question

    What are the hardware requirements for deployment?

    answer

    The software runs on a local server equipped with an RTX 3090 24GB GPU. It handles ASR, OCR, visual verification, and transcription locally. No cloud resources or external IT integration are required for the core functionality.

  • topic

    data

    question

    Is patient data sent to the cloud?

    answer

    No. All data processing is performed on-premise. Patient data never leaves the hospital's local infrastructure. Raw recordings and images are deleted immediately after processing to minimize data retention.

  • topic

    certification

    question

    Does this product have FDA or CE certification?

    answer

    No. This product is currently a research and development project deployed in partner hospitals. It does not hold FDA, CE, or other medical device certifications. It is intended as a clinical documentation aid, and all outputs require physician review.

  • topic

    languages

    question

    Which languages are supported for transcription and documentation?

    answer

    The system is optimized for clinical English and Chinese contexts as per current deployment. Support for other languages depends on the underlying ASR and LLM models configured for the specific hospital environment.

  • topic

    training

    question

    How much training is required for residents?

    answer

    The software is designed for minimal interaction. Residents wear the badge (when available) or use the software interface for specific tasks like lab OCR. Training focuses on reviewing AI-generated drafts and confirming unclear items.

  • topic
