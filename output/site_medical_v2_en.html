solution

A hybrid software and hardware solution designed for paediatric residents. The software runs entirely on local hospital GPUs (RTX 3090), handling ASR, OCR, and document generation without cloud API dependency. It integrates with a planned smart badge to automate audio and visual data capture, ensuring accurate context linkage to patient records while maintaining strict data privacy.

compliance

data_sovereignty

All patient data processing, including OCR, visual analysis, transcription, and de-identification, occurs 100% on local hospital GPUs. No data is transmitted to cloud APIs. Original recordings and images are deleted immediately after processing. This architecture supports compliance with data localisation requirements such as GDPR, Indonesia's PDPA, and Saudi/UAE data sovereignty regulations, though specific legal obligations must be verified per market.

market_access

The solution is designed for local deployment, reducing reliance on cross-border data transfer mechanisms. However, regulatory certification (e.g., medical device registration) varies by country and is not claimed here. Compliance with local healthcare IT standards requires project-specific verification.
